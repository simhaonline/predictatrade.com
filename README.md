# Predict-A-Trade Website

Predict-A-Trade v1.0.0 is a static public website for XAUUSD market intelligence and probability analytics.

## Project contents

- `index.html` — homepage shell and metadata.
- `assets/` — website JavaScript and CSS bundles.
- `media/` — website imagery.
- `legal/` — legal and trust-center pages.
- `cookie-consent.js` and `cookie-settings.js` — cookie preference controls.
- `manifest.json`, `service-worker.js`, and `media/icon-*.webp` — installable PWA metadata, offline app shell, and app icons.
- `robots.txt`, `sitemap.xml`, and `llms.txt` — site metadata.
- `.htaccess` — optional Apache configuration.

## Legal & Trust Center

The homepage footer includes a `Legal & Trust Center` link to `/legal/`, together with the policy, privacy, complaints, sitemap, and cookie links.

The legal pages describe the product as decision-support and probability analytics. They do not promise profits, guaranteed outcomes, or trading performance.

## Technical scope

This repository contains the public presentation layer only. It does not contain live trading execution, payment processing, private APIs, credentials, or proprietary trading logic.

The website is plain HTML, CSS, and browser JavaScript. It has no Node.js application, database, or required `.env` file.

## Mobile & PWA

The homepage uses a fluid single-column layout below 768px, responsive imagery, and touch-friendly controls. The service worker uses a cache-first strategy for the public app shell and falls back to the homepage when navigating offline.

## The Living Analysis hero

The homepage hero includes a self-contained vanilla SVG animation in `living-analysis.js` and `living-analysis.css`. The original `media/pat-hero-signal.webp` remains in the markup as the poster fallback for no-JavaScript visitors, crawlers, and social previews. A standalone preview is available at `/preview-living-analysis.html`.

The loop is 10 seconds: 0–2s `READ THE NOISE`, 2–5s `FIND THE SHAPE`, 5–8s `SEE THE SIGNAL`, and 8–10s `SETTLE`. Motion uses ease-out transitions only and deliberately avoids prices, ticks, counters, or live-feed behaviour. The animation is initialized only when its container enters the viewport and pauses when it leaves the viewport or the document is hidden. Reduced-motion users receive the final measured-signal state.

Tunables are at the top of `living-analysis.js`: `loopMs`, the four `phases` durations, `candleSeed`, `signalPeriod`, and the brand colors. Candle data is generated by `seededCandles(seed)`. To use approved XAUUSD data later, replace that function’s returned candle array with normalized `{open, close, high, low}` values; the rendering and animation layers do not need to change. The current graphic is illustrative and does not represent live prices or a trading recommendation.

The hero also requests a server-side XAUUSD quote from `/api/xauusd.php`. Configure the Financial Modeling Prep key in Plesk as the environment variable `PAT_FMP_API_KEY`; do not place the key in JavaScript, HTML, Git, or a public `.env` file. The proxy caches the result briefly, exposes only normalized quote fields, and stops polling when the hero is off-screen or the tab is hidden. The live reference line is contextual display only, not a trading signal.
